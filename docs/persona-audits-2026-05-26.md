# 7-Persona Mobile Audit — 2026-05-26

Output of the parallel sub-agent batch. Each persona walked the AcreOS
mobile experience, benchmarked against actual category competitors,
and returned: 5 frictions · 3 missing journeys · closest competitive
feel · leapfrog opportunity.

## Cross-persona patterns (showed up in 3+ audits)

1. **Mobile bottom nav is universal-blind.** Hardcoded 4 tabs
   (Today/Deals/Money/AI Hub) ignore every non-Land-Flipper workflow.
   Note routes, rent-roll, maintenance, tenants, leases, buyer-blasts,
   redemption-clock all live in the More drawer. Every persona audit
   complained.
2. **No mobile push notifications.** Redemption deadlines, EMD timers,
   payment arrivals, permit approvals, lease expiries, maintenance —
   all need push, all missing.
3. **Tables crammed on mobile.** Properties, leads, deals, rent-roll,
   redemption-clock, permits, contractors all break on small screens.
4. **No unified Inbox surface.** Wholesaler buyer responses, Landlord
   tenant messages, Note borrower texts, Land Flipper callbacks all
   converge on the same missing UX: a triage feed for inbound responses
   to outreach.
5. **Generic dashboard, not persona-specific health.** Every persona
   shows the same Today/portfolio surface; no persona sees their actual
   important numbers.

## Per-persona leapfrog opportunity (1-liner each)

| Persona | Leapfrog |
|---|---|
| **Land Flipper** | "Response Handler" tab — inbound callbacks + SMS + mail-opens with one-tap log-contact + advance-stage + capture-offer |
| **Note Investor** | Borrower texts "wire sent" → tap in-app link → record with auto-fill from amortization schedule |
| **Wholesaler** | Mobile EMD + Assignment Dashboard — countdown + interested-buyer count + one-tap actions, all on Today |
| **Fix & Flip** | On-site photo → AI-tag → auto-rehab-line-items → one-tap lender draw request, eliminating 5 days of inspection scheduling |
| **Tax-Delinquent** | Mobile-first power user — courthouse mode (offline) + push redemption alerts + 3-click quiet-title dashboard |
| **Buy-and-Hold Landlord** | Lease renewal preflights with 60/30/14 day push notifications + one-tap tenant contact |
| **Subdivider** | "Plat Status" card with active-permit countdowns + buyer-inquiry inbox by lot — no app switching |

**Strongest leapfrog candidate: Tax-Delinquent.** Weakest competitive
field, clearest missing journey (courthouse-mode), most marketable
story.

**Highest universal-impact change: persona-aware bottom nav + Inbox surface.**
Touches all 7 personas, not just one.
