## 4. Vocabulary — Key Terms

| Term | Definition / Usage |
|---|---|
| **No-Code** | Core positioning — build apps and workflows without programming. Drag-and-drop builder. |
| **Workspaces** | Organizational containers for apps, tasks, and team members. Each workspace can represent a project, client, or business function. |

## 5. Core Workflows

### 5a. Build a Custom CRM (No-Code)
Create custom apps for Leads, Properties, Deals, Contacts using drag-and-drop builder or pre-built App Packs. Define custom fields, relationships, and views. The Real Estate Investment App Pack provides 9 apps and 50+ automations out of the box.

### 5b. Capture and Route Leads
Create Webforms for lead capture that feed directly into the Leads app. Automate lead routing and assignment to team members. Set up stage-based tracking (New > Contacted > Negotiating > Under Contract > Closed) to visualize deal progression.

### 5c. Automate Follow-Up Workflows
Build If-This-Then-That automations: auto-assign tasks when a lead reaches a stage, send follow-up emails on a schedule, trigger notifications when deadlines approach, update statuses based on activity. Premium tier adds date/time triggers and advanced automation (5M runs/mo).

### 5d. Collaborate Across Teams
Real-time comments on items, @mentions, shared calendars, file attachments, and activity streams. Invite clients and external parties for free. Light user roles for view-only team members.

### 5e. Report and Analyze
Visual reports and interactive sales dashboards (Premium only). Track pipeline value, deal velocity, conversion rates. Export data or use API for external reporting.

## 7. What Podio Communicates Clearly That AcreOS Does Not

1. **Customization depth.** Podio's entire pitch is "build it your way" — no-code builder, custom fields, custom apps, custom views. AcreOS presents a fixed feature set. For users who want control over their data model, Podio's message is more compelling.

2. **Free external users.** "Clients, freelancers and other external parties... for free" is a powerful message for teams that work with title companies, attorneys, agents, or contractors. AcreOS's pricing is seat-based with no external user concept.

3. **Multi-view flexibility.** Kanban, calendar, table, and badge views for the same data. AcreOS's landing page does not mention how data is visualized beyond "interactive maps."

4. **Security certifications.** ISO27001, SOC2 Type II compliance is stated prominently. AcreOS does not mention security or compliance certifications.

5. **API-first positioning.** Podio leads with integration flexibility and API access. AcreOS does not mention API access or integrations on its landing page.

6. **Workflow automation as a headline capability.** Podio's three pillars are Customize, Automate, Collaborate. Automation is a first-class concept. AcreOS mentions "Campaign Automation" but does not position workflow automation as a platform capability.

## 8. Transferable Patterns AcreOS Should Adopt

1. **Communicate customization options.** Even if AcreOS is opinionated (not no-code), showing that users can customize views, fields, stages, and workflows reduces the "will this fit my business?" anxiety that drives investors to Podio.

2. **Offer free external/client seats.** Real estate transactions involve multiple parties (title, attorney, lender, agent). If AcreOS could offer free read-only or limited access for transaction participants, it would be a significant competitive advantage over both Podio's model and PropStream's team pricing.

3. **Add multiple data views.** Kanban boards for deal pipeline, calendar views for follow-ups, table views for bulk data management. AcreOS should ensure these are visible on the landing page — they are table-stakes for CRM-like tools.

4. **State security posture.** If AcreOS has any compliance certifications, encryption standards, or SOC2 aspirations, they should be on the landing page. For enterprise and team buyers, this is a gating criterion.

5. **Position integrations.** Podio thrives on its integration ecosystem. AcreOS should prominently list what it connects to (Zapier, webhooks, API access, specific RE tools) even if the list is short today.

6. **Use the "three pillars" framework.** Podio's Customize / Automate / Collaborate structure is immediately scannable. AcreOS's six feature cards are harder to parse. Consider organizing features into 3-4 named pillars that tell a story (e.g., "Find / Analyze / Reach / Close").

7. **Address the Podio migration path.** Many RE investors are currently on Podio and frustrated by setup complexity. AcreOS should consider a "Switching from Podio?" page or migration guide. Podio's weakness (weeks/months of setup) is AcreOS's strength (purpose-built, works out of the box). This is an under-exploited competitive angle.
