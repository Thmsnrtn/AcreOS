## NEW P0 Issues

### P0-SWEEP-001: Founder routes v6-v14 missing authentication middleware
- **Severity**: P0 (Critical Security)
- **Location**: `server/routes.ts` lines 1318-1333
- **Detail**: `registerFounderV6Routes` through `registerFounderV14Routes` are called with just `app` — they register routes directly on the Express app without `isAuthenticated` middleware. The global `clerkMiddleware` only populates `req.auth` but does NOT enforce authentication. The per-route `isAuthenticated` middleware is what blocks unauthenticated access, and none of these 8 route files apply it. All `/api/founder/v6/*`, `/api/founder/v7/*`, ... `/api/founder/v14/*` endpoints are accessible without authentication.
- **Contrast**: `routes-founder-intelligence.ts` and `routes-setup.ts` ARE correctly mounted with `isAuthenticated` (lines 1249, 1255). The v6-v14 files are the outliers.
- **Fix**: Either add `isAuthenticated` + `getOrCreateOrg` to each `app.use()` call in routes.ts, or apply `isAuthenticated` as per-route middleware inside each register function.
