## Top 8 by value-per-effort for AcreOS

Split by whether it upgrades an existing DD check or adds a new one:

1. **FEMA NFHL REST (upgrade: flood).** One point-in-polygon query against the public MapServer returns the authoritative flood zone, panel, and BFE per parcel. This is the single highest-credibility upgrade from stub to "real FEMA data" and it is a plain ArcGIS REST query — an afternoon of work, fits the provider-registry pattern (cacheable, no key).
2. **NRCS Soil Data Access (upgrade: soil).** One T-SQL POST per parcel geometry returns septic-tank-absorption-field ratings and farmland classification — exactly the two attributes land buyers ask about. Slightly more effort than NFHL (SQL over the SSURGO schema) but no auth, no cost, sub-parcel granularity.
3. **USFWS NWI REST (upgrade: wetlands).** Same ArcGIS-REST pattern as NFHL; intersect the parcel with wetland polygons and return classification codes. Trivial once NFHL is built — reuse the same client.
4. **FEMA National Risk Index (new: composite risk).** One-time CSV ingest keyed by census tract gives you 18-hazard risk scores, expected annual loss, and percentile ratings for every US tract — an entire "risk score" feature from a single static file. Best raw value-per-effort on this list; refresh annually.
5. **USFS Wildfire Risk to Communities / WHP (new: wildfire).** Either identify against the 30 m ImageServer per point, or ingest the free national community/county spreadsheet. Wildfire is a top concern for rural/western land and no current check covers it.
6. **EPA FRS + ECHO radius search (upgrade: environmental).** `get_facilities` by lat/lon + radius consolidates Superfund/NPL, brownfields, RCRA, and enforcement history into one federated call, replacing manual lookups; layer UST Finder for tanks. Medium effort (multiple EPA APIs, pagination quirks) but converts the weakest manual check into a defensible one.
7. **FCC Broadband Data Collection (new: broadband).** Per-location availability by technology/speed is public (free token). For a land-first platform this is a differentiating livability signal buyers can't easily get elsewhere; bulk state CSVs make it cheap to pre-index.
8. **USGS seismic design service (new: seismic).** A single GET with lat/lon returns hazard/design values — probably the lowest-effort net-new check on the list; lower buyer salience than wildfire/broadband, hence last.

**Deliberately below the line:** tax/assessment cannot be upgraded federally (confirmed no national open source — stays county-by-county or paid via Regrid/ATTOM); HIFLD power-line proximity is no longer a dependable open source post-shutdown (archived snapshots only, will go stale); pipelines (PHMSA NPMS) are view-only; ND oil & gas is paywalled (build TX/OK first); NOAA storm events and BLM mining claims are good later-stage enrichments (mining claims worth prioritizing if western acreage is a core market — it is fully open with REST + bulk).

One licensing flag: everything ranked above is US Government public-domain work except FCC BDC (public availability data, but the CostQuest location Fabric underneath is licensed — store only availability results, not Fabric records) and state well logs, where terms vary per state (marked unclear as a class; TX/WA/MN verified open).
