## Memo shape (strict, so synthesis can cluster mechanically)

```
# <Handle> — <One-phrase lens>

**Reading list (what I read before writing):**
- doc 1
- doc 2
- doc 3

**State read (1 paragraph):**
…

**Push forward — my 5 moves (ranked):**
1. <move> — <why now> — <effort estimate>
2. …
3. …
4. …
5. …

**What I'd defer (and why):**
- …

**What scares me most (one named risk + mitigation):**
…
```

Word-cap: ~400 each. Each persona must name ≥3 specific files / surfaces /
KPIs from the AcreOS codebase (no generic SaaS verbiage). Each new persona
gets a 1-paragraph backstory in their memo (last role, scar that shaped
them, current obsession) so the lens is concrete.

## Anti-consensus instruction

Each persona must disagree with at least one prior recommendation when
reasonable. The synthesis values divergence — a 20-memo "polish and
grow" pile is worse than a 20-memo argument.
