# AcreOS customers — first 100

Last updated: 2026-05-29 by Tom

This file is the qualitative narrative tracker for our first 100 paying
customers — one human-readable line per org, with the context the
auto-computed `/founder/customers` page can't capture (where we met
them, who introduced us, what they're using AcreOS for, what they almost
churned over). The page handles the numbers; this file handles the
story.

Conventions:
- Add new rows at the TOP of the relevant section.
- Update `Last updated` at the top of the file whenever you touch it.
- Keep one line per org. If you need a paragraph, drop a link to a Notion
  page in the `note:` field.
- When an org moves between sections (trial → paying, paying → churned),
  cut/paste the line; don't duplicate.
- Counts in the section headers should match the line count below them.
