Key facts

Status
Prototype is feature-complete for design review. Nothing in /acreos ships — it's a spec.
Canonical pages
Where multiple versions exist (e.g. CommandCenter, CommandCenterB, CommandCenterC), the highest letter wins. Older ones stay in the prototype but don't get ported. Full table in §3.
Globals
Every window.* reference is a TODO. Each maps to a hook, router action, or delete. Full table in §4.
Data
All lists/tables/charts are frozen literals. Replace with Tanstack Query against API endpoints sketched in §6.
Tweaks panel
Review tool, not a feature. Most toggles ship as nothing; three become real settings. See §9.
